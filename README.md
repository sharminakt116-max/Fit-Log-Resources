Project Name:fit-log-resources

FITLOG is a modern workout library and workout planning web application. 
Users can browse workouts, view workout details, add exercises to today's plan, 
and save workouts for later.

Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- React Toastify
- LocalStorage
- REST API

 Key Features

1. Workout Library
   - Browse workouts with images, muscle groups, equipment, duration, calories, and ratings.

2. Workout Details
   - View complete workout information, specifications, and step-by-step instructions.

3. My Plan
   - Add workouts to today's plan and manage planned exercises.

4. Save for Later
   - Save workouts and access them later from the My Plan page.

5. Sort Workouts
   - Sort workouts by Duration, Calories, or Rating.
